How to read these numbers

This governor board applies the governor-only same-state historical polling-error method to a dated, attributed On Point Politics polling average as the current polling input. The adjustment now uses ONLY earlier governor races from the same state, not Senate or presidential election errors. The past-only gubernatorial backtest remains unfavorable to adjustment on the audited sample. Poll counts reflect the publisher’s records, not distinct independent forecasters. Candidate rosters are cross-referenced with the National Governors Association. No county result is treated as live until a verified source has provided it.

Did the historical correction improve governor forecasts?

This is an out-of-sample historical replay: for each tested governor election, the adjustment uses only earlier governor polling errors in that state, with 50% / 30% / 20% weights for the newest three available gubernatorial cycles. The 2026 correction is NEVER applied retrospectively, and no Senate/presidential results enter governor estimates. The historical sample is selective and does not establish national forecast accuracy.
